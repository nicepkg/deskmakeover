# DeskMakeover Docs

**Now:** DeskMakeover, Chinese product name "桌面美颜" (renamed by ADR-0002), is a new Windows desktop makeover app. The MVP is a one-click, fully reversible desktop icon styler for Windows 10 and Windows 11: single main screen, before/after mirror, dark-first squircle visual system. Foundation (domain, rendering, scanning, snapshots, journaled ops) is built and tested; UI/UX v2 rebuild is in progress.

## Version Timeline

- Unreleased - Foundation built (60 tests green); UI/UX v2 rebuild underway per ADR-0002.
