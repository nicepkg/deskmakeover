# UI/UX v2 — One-Click Product Form Implementation Plan

**Goal:** Rebuild the product surface per ADR-0002: single main screen, before/after
mirror, one-click apply with invisible snapshot, ever-present restore, arrow-removal
trust flow, dark-first squircle visual system.
**Architecture:** Presentation stays in `DeskMakeover.App` (view model + orchestrator
over existing engines). No domain/rendering/operations contracts change except
additive presentation needs (original+styled image pairs). Privileged work lands in
`DeskMakeover.ElevatedHelper` behind fixed verbs.
**Tech stack:** .NET 10 WPF + built-in Fluent theme (`ThemeMode`, no third-party UI
lib), DWM interop, xUnit.
