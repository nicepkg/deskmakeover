# Prototype — historical reference only

`桌面美颜 v2.dc.html` (+ `support.js`) is the owner's original interactive design prototype from the
early product-form exploration (the v2 prototype, ADR-0008 era). It is kept for reference and
provenance only.

**It is NOT the source of truth.** It was demoted from "the binding UI/UX contract" by
[ADR-0012](../../decisions/0012-premium-ui-redesign.md), and the product has since gone through the
v3 "Premium Flat" redesign ([ADR-0013](../../decisions/0013-v3-flat-light-redesign.md)) and the
Tauri 2 + Rust replatform ([ADR-0019](../../decisions/0019-tauri-rust-replatform.md)). The living
truth is the specs (`docs/specs/`). Do not implement against this prototype.
